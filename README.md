# FinanceMate
An Android application I developed to help my mother manage her mini market's finances. It simplifies bookkeeping by recording income and expenses, tracking profits, and generating financial summaries, applying my Computer Science knowledge to solve a real-world problem.


FinanceMate Application

----------------------------------------
1. Install the provided APK file on your Android device
2. Allow installation from unknown sources if needed
3. Open the app
----------------------------------------

How to Use
1. Sign up for a new account
2. Log in with your username and password
3. Use the Home Dashboard to navigate
4. Add income or expense transactions
5. Manage categories if needed
6. View transactions and summaries
7. Export data as PDF if required

----------------------------------------
System Requirements
- Android device or emulator
- Android Studio (for development)
- No internet connection required
